01 — What is HTML?

Understand the purpose before writing a single tag.

🌐

The Language of the Web

HTML stands for HyperText Markup Language. It is the standard language used to create the structure of every webpage on the internet.

🏗️

Structure, Not Style

HTML defines what content is — a heading, a paragraph, an image, a link. CSS adds appearance. JavaScript adds behavior.

🧱

Built with Tags

HTML is made up of elements written as tags like <h1>, <p>, and <img>. Tags wrap around content to give it meaning.


The Web Trio: Think of HTML as the skeleton of a webpage, CSS as the clothing and colors, and JavaScript as the muscles and behavior.

03 — The HTML Document Structure

Every HTML file must follow this skeleton.

<!-- Every HTML document starts with a DOCTYPE declaration --> <!DOCTYPE html> <html lang="en">   <head>     <!-- Meta info: not visible on the page -->     <meta charset="UTF-8">     <meta name="viewport" content="width=device-width, initial-scale=1.0">     <title>My First Webpage</title>   </head>   <body>     <!-- Everything the user sees goes here -->     <h1>Hello, World!</h1>     <p>Welcome to my first webpage.</p>   </body> </html>

<head> — Contains metadata: the page title, character set, links to CSS, and SEO info. The user does not see the head content directly.
<body> — Everything the user actually sees on the page goes inside the body: text, images, links, forms, and more.

04 — Key Concepts

Switch between topics to explore.

Attributes

Attributes provide extra information about an element. They go inside the opening tag.

<!-- href is an attribute of <a> --> <a href="https://example.com" target="_blank">Click here</a> <!-- src and alt are attributes of <img> --> <img src="photo.jpg" alt="A description"> <!-- id and class are used by CSS and JavaScript --> <p id="intro" class="highlight">Hello!</p>

Nesting Elements

HTML elements can be placed inside other elements. The inner element must be closed before the outer one.

<!-- ✅ Correct nesting --> <ul>   <li>First item</li>   <li>Second item</li> </ul> <!-- ❌ Wrong — tags are crossed --> <b><i>text</b></i>
⚠️ Rule: Always close the innermost tag first. Think of it like stacking boxes — you close the inner box before closing the outer one.

Semantic HTML

Semantic tags tell the browser (and developers) what a section means, not just how it looks.

<!-- Non-semantic (vague) --> <div class="header">...</div> <div class="nav">...</div> <!-- Semantic (meaningful) ✅ --> <header>...</header> <nav>...</nav> <main>...</main> <article>...</article> <footer>...</footer>

Self-Closing Tags

Some HTML elements do not have content inside them and do not need a closing tag.

<img src="photo.jpg" alt="Photo"> <!-- Image --> <br> <!-- Line break --> <hr> <!-- Horizontal rule --> <input type="text"> <!-- Text input --> <meta charset="UTF-8"> <!-- Metadata --> <link rel="stylesheet" href="style.css">

Install VS Code
